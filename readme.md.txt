AI Lead Intelligence Platform

A geospatial AI-powered system that discovers real-world businesses, enriches their data using external sources, and scores lead quality based on completeness and relevance.

The platform extracts businesses globally using OpenStreetMap, enhances them with Wikidata and web scraping, and visualizes results on an interactive map with filtering and export capabilities.

This project demonstrates end-to-end system design including API integration, data engineering, background processing, and geospatial visualization using Python.

Built with Python, Streamlit, Pandas, Requests, BeautifulSoup, Folium, OpenStreetMap API, and Wikidata API.
